This folder contain all reports and reflections connected to this project. This includes all Jupyter Notebooks. 

We are not sure however if our python project should compose a series of notebooks or python files for training and producing models. We store the notebooks here for now.

Setup:
1. python -m venv .venv (python3 or py may be candidate keywords instead of python)
2. source .venv/bin/activate  (or .venv\Scripts\activate on Windows)
3. pip install -r requirements.txt


Adding a new requirement:
1. pip install <PACKAGE>
2. add package manually in requirements.txt
